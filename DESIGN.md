# DESIGN.md — Design Guidelines

## 1. Design Philosophy
- Create distinctive, premium, modern interfaces.
- Avoid generic AI-generated website aesthetics.
- Every page must have a clear visual identity.
- Prioritize usability, clarity, and visual hierarchy.
- Design should feel intentionally crafted, not template-generated.

## 2. Visual Design
- Use a consistent color palette.
- Establish strong typography hierarchy.
- Use whitespace intentionally.
- Avoid excessive gradients, shadows, and rounded cards.
- Avoid unnecessary decorative elements.
- Use subtle animations only when they improve UX.

## 3. Typography
- Use distinctive, readable fonts.
- Establish clear heading and body text hierarchy.
- Avoid using too many font families.
- Maintain consistent font weights and spacing.

## 4. Layout
- Use intentional layouts instead of repetitive card grids.
- Create strong visual hierarchy.
- Maintain consistent spacing.
- Ensure responsive behavior on mobile, tablet, and desktop.
- Avoid excessive empty sections.

## 5. Components
- Components must be reusable and consistent.
- Buttons must have clear visual states.
- Forms must be accessible and intuitive.
- Navigation must be simple and predictable.
- Avoid unnecessary UI components.

## 6. Anti-AI-Slop Rules
NEVER:
- Use generic purple-to-blue gradients everywhere.
- Make every section a rounded card.
- Use excessive glassmorphism.
- Add random floating decorative elements.
- Use emoji as professional icons.
- Create repetitive landing page layouts.
- Add meaningless marketing copy.
- Use arbitrary colors or inconsistent spacing.

## 7. User Experience
- Accessibility is mandatory.
- Ensure good color contrast.
- Provide clear hover, focus, and active states.
- Prioritize performance.
- Make interactions feel natural.

## 8. Responsive Design
- Mobile-first approach.
- No horizontal overflow.
- Maintain readable typography at every breakpoint.
- Navigation must adapt properly to smaller screens.

## 9. Code Quality
- Use reusable components.
- Keep code clean and maintainable.
- Follow existing project conventions.
- Avoid unnecessary dependencies.
- Preserve existing functionality.

## 10. Final Quality Check
Before completing any UI:
- Check visual consistency.
- Check responsive layouts.
- Check typography and spacing.
- Check accessibility.
- Remove generic AI-looking elements.
- Ensure the result feels professionally designed.

**Golden Rule:** Every design decision must have a clear purpose. Never sacrifice design quality for speed.
